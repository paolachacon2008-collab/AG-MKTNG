2. Qué datos recoge esta web

Esta web no tiene formularios, no pide registro y no guarda datos personales de quien la visita. Si llamas por teléfono o escribes por redes sociales, el restaurante usará tus datos solo para atender tu reserva, pedido o consulta.

3. Base legal y conservación

La base legal es tu consentimiento o la gestión de lo que nos pides (artículo 6.1 a) y b) del Reglamento General de Protección de Datos, RGPD). Los datos se guardan solo el tiempo necesario para atenderte y cumplir obligaciones legales.

4. Servicios de terceros

El hosting de la web puede registrar datos técnicos de las visitas (como la dirección IP) por motivos de seguridad. El mapa de Google solo se carga si pulsas «Cargar el mapa»; a partir de ese momento se aplica la política de privacidad de Google.
